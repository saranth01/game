# ดวงดาว & ไพ่ — เกมดูดวงแบบตะวันตก + ทาโรต์

เกมดูดวงไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต
คำนวณ **Sun / Moon / Rising** จากวัน–เวลา–พิกัดที่เกิดจริง แล้วอ่านต่อด้วยไพ่ทาโรต์ 3 ใบ

```
เปิดไฟล์ index.html ด้วยเบราว์เซอร์  (ดับเบิลคลิกได้เลย)
```

## ขั้นตอนในเกม

1. **กรอกข้อมูลเกิด** — วัน/เดือน/ปี, เวลา, latitude, longitude, เขตเวลา
   (ไม่รู้เวลาเกิดก็เล่นได้ แต่จะข้าม Rising ไป เพราะลัคนาเปลี่ยนราศีทุก ~2 ชั่วโมง เดาไม่ได้จริง ๆ)
2. **อ่านตัวตน** — Sun = แกนกลาง, Moon = โลกข้างใน, Rising = ภาพที่คนอื่นเห็น
   พร้อมบทอ่านรวมที่ชี้ความขัดแย้งภายใน จุดแข็ง และกับดักประจำตัว
3. **ตั้งคำถาม** — เลือกหมวด + พิมพ์คำถาม (บังคับ ต้องถามก่อนถึงจับไพ่ได้)
4. **เปิดไพ่** — สำรับคว่ำ 78 ใบ เลือก 3 ใบ: ใบแรก = ไพ่หลัก, ใบ 2–3 = ไพ่ขยาย
5. **คำอ่าน** — ตีความไพ่แต่ละใบ *ผ่านเลนส์ Sun/Moon/Rising ของผู้ถาม* แล้วสรุปเป็นคำแนะนำที่ทำได้จริง

## ตรรกะการอ่าน

ลำดับนี้ตั้งใจให้เหมือนหมอดูที่ทำการบ้านมาก่อน ไม่ใช่เปิดตำราแปลไพ่ทีละใบ

```
1) buildPersona()   เข้าใจตัวตนก่อน — ธาตุของ Sun/Moon/Rising, ความขัดแย้งภายใน,
                    modality (ริเริ่ม/มั่นคง/ยืดหยุ่น), จุดแข็ง, กับดัก
2) readCard()       อ่านความหมายไพ่ตามตำแหน่ง (หลัก/ขยาย1/ขยาย2) และตั้ง/กลับหัว
3) personalLens()   ผูกไพ่เข้ากับตัวตน — ธาตุไพ่ปะทะ/เสริมธาตุเจ้าชะตา,
                    ไพ่กลับหัว × ธาตุดวงจันทร์, ชุดไพ่ × ราศีลัคนา, ไพ่ชุดใหญ่
4) buildReading()   ประเมินแนวโน้มรวมจากขั้วของไพ่ (ไพ่หลักถ่วงน้ำหนัก ×2),
                    นับไพ่ชุดใหญ่/ไพ่กลับหัว/ชุดไพ่ที่ซ้ำ แล้วสรุป + สิ่งที่ทำได้สัปดาห์นี้
```

โทนการเขียนตั้งใจให้เป็น **เพื่อนที่เข้าใจเพื่อน** — ไม่ฟันธงชี้เป็นชี้ตาย ไม่ขู่
ไม่ใช้คำว่าเคราะห์/ดวงตก และปิดท้ายด้วยสิ่งที่ลงมือทำได้จริง

## สูตรดาราศาสตร์ที่ใช้

อ้างอิง Jean Meeus, *Astronomical Algorithms* (ฉบับที่ 2) เขียนเป็น JavaScript ล้วนในไฟล์

| ค่า | ที่มา | ความคลาดเคลื่อน |
|---|---|---|
| Julian Day | บทที่ 7 | แม่นยำ |
| ลองจิจูดดวงอาทิตย์ | บทที่ 25 (ตำแหน่งปรากฏ) | < 0.01° |
| ลองจิจูดดวงจันทร์ | บทที่ 47 — ตาราง 47.A 59 เทอมแรก + A1/A2/E | ≈ 0.001° เทียบตัวอย่างในตำรา |
| Sidereal time | สูตร 12.4 | < 0.001° |
| ความเอียงแกนโลก | สูตร 22.2 | < 0.001° |
| ลัคนา (Ascendant) | `atan2(cos RAMC, −(sin RAMC·cos ε + tan φ·sin ε))` | ตามค่าข้างต้น |

ใช้ระบบ **Tropical zodiac** (ราศีอิงวิษุวัต) ซึ่งเป็นระบบมาตรฐานของโหราศาสตร์ตะวันตก

### ข้อจำกัดที่ควรรู้

- โปรแกรมไม่รู้จัก Daylight Saving Time ในอดีต — ถ้าเกิดในประเทศ/ปีที่มี DST
  ให้เลือกเขตเวลาที่บวกชั่วโมงเพิ่มแล้วเอง (ไทยไม่มี DST ตั้งแต่ปี 2495 จึงใช้ UTC+7 ได้ตลอด)
- ใช้ UT ≈ TT (ไม่ชดเชย ΔT) — มีผลไม่ถึง 1 ลิปดาสำหรับวันเกิดในศตวรรษที่ 20–21
- รองรับปีเกิด ค.ศ. 1600–2200
- ถ้าดวงจันทร์อยู่ที่รอยต่อราศี (< 0.6° หรือ > 29.4°) โปรแกรมจะขึ้นคำเตือนให้เช็กเวลาเกิดอีกครั้ง

## โครงสร้างไฟล์

`index.html` ไฟล์เดียว แบ่งเป็น 5 บล็อกสคริปต์ที่แยกทดสอบได้

| บล็อก | เนื้อหา |
|---|---|
| `#engine` | คณิตศาสตร์ดาราศาสตร์ (pure function ไม่ยุ่งกับ DOM) |
| `#signs` | ข้อมูล 12 ราศี × 3 บทบาท (Sun/Moon/Rising) |
| `#tarot-major` / `#tarot-minor-1` / `#tarot-minor-2` | ไพ่ 78 ใบ |
| `#reading` | เครื่องตีความ + การสับไพ่ |
| `#ui` | หน้าจอและการโต้ตอบ |

ไม่มีรูปภาพภายนอก ไม่มี CDN ไม่มี build step — หน้าไพ่วาดด้วย CSS และตัวอักษรล้วน
รองรับมือถือ, `prefers-reduced-motion` และการสั่งพิมพ์ (ปุ่มบันทึก/พิมพ์ใช้ print stylesheet)

## การทดสอบ

ตรรกะทั้งหมดอยู่ในบล็อกสคริปต์ที่ดึงออกมารันด้วย Node ได้ เช่น

```js
// ดึงบล็อกเอนจินออกมาเป็นโมดูล แล้วเทียบกับค่าตัวอย่างในตำรา Meeus
const code = html.match(/<script id="engine">([\s\S]*?)<\/script>/)[1];
// 1992-10-13 0h TT → ดวงอาทิตย์ 199.907°   (Meeus 25.b)
// 1992-04-12 0h TT → ดวงจันทร์ 133.163°    (Meeus 47.a)
// 1987-04-10 0h UT → GMST 197.693°         (Meeus 12.a)
```

ตรวจแล้วว่า: ลัคนากวาดครบ 12 ราศีเรียงลำดับใน 24 ชั่วโมง (ทดสอบที่กรุงเทพฯ ลอนดอน ซิดนีย์),
สุ่มอ่าน 1,500 รอบไม่มีไพ่ซ้ำในสเปรดเดียวและไม่มีข้อความหลุด และเดินครบ flow บน Chromium
ทั้ง desktop และ mobile โดยไม่มี console error
