# ดวงดาว & ไพ่ — เกมดูดวงตะวันตก + ทาโรต์

เกมดูดวงไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต (ยกเว้นฟอนต์ Prompt)

```
เปิด index.html ด้วยเบราว์เซอร์
```

## ขั้นตอนในเกม

1. **ข้อมูลเกิด** — วัน/เดือน/ปี, เวลา, และ **พิมพ์ชื่อสถานที่เกิด** (77 จังหวัดไทย + เมืองใหญ่ทั่วโลก)
   ระบบหาพิกัดกับเขตเวลาให้เอง · ไม่รู้เวลาเกิดก็เล่นได้ แต่จะข้าม Rising ไปแทนการเดา
2. **อ่านตัวตน** — วงล้อราศีที่วางตำแหน่ง ☉ ☽ ASC ตามองศาจริง + คำอ่าน Sun / Moon / Rising
3. **ตั้งคำถาม** — เลือกหมวดแล้วเล่าคำถาม (ยิ่งเล่าบริบท ยิ่งอ่านได้ขาด)
4. **เปิดไพ่ 9 ใบ ใน 3 สเปรด** สเปรดละ 3 ใบ (ไพ่หลัก 1 + ไพ่ขยาย 2)
5. **คำอ่าน** — เริ่มจากอ่านคำถามก่อน แล้วค่อยอ่านไพ่

## ตรรกะการอ่าน

```
1) analyzeQuestion()   อ่านรูปประโยคของคำถาม หา "คำถามจริง" ที่ซ่อนอยู่
                       14 สัญญาณ เช่น ขออนุญาต (ควร…ไหม) · ฝากคำตอบไว้ที่คนอื่น ·
                       ทน/ยื้อ · ถูกทิ้ง · โทษตัวเอง · ต้นทุนจม · กลัว · ล้า · ขอการยืนยัน
                       แล้วผูกกับธาตุดวงจันทร์ (วิธีที่ใจทำงาน) และธาตุลัคนา (หน้ากากที่คนเห็น)
2) buildPersona()      ธาตุของ Sun/Moon/Rising, ความขัดแย้งภายใน, จุดแข็ง, กับดัก
3) 3 สเปรด × 3 ใบ
   I  ขยายสถานการณ์   แก่นของเรื่อง / แรงที่ผลักอยู่เบื้องหลัง / มุมที่ยังไม่ถูกมอง
   II ความรู้สึกคนถาม  อ่านจากชั้นอารมณ์เฉพาะของไพ่ 78 ใบ ผ่านเลนส์ดวงจันทร์
   III คำทำนาย        ทิศทางที่ไป + จังหวะเวลาตามชุดไพ่ / เงื่อนไขที่พลิกผล / สิ่งที่ต้องปล่อย
4) สังเคราะห์          ช่องว่างระหว่างสถานการณ์กับความรู้สึก · แนวโน้ม · ประโยคที่อาจไม่อยากได้ยิน ·
                       สิ่งที่ทำได้สัปดาห์นี้
```

**โทนเสียง** — คนอ่านไพ่ในเกมนี้ถูกเขียนให้เป็น ☉ เมถุน · ☽ พิจิก · ↑ เมถุน:
มองทะลุถึงชั้นที่คนไม่พูด แต่เล่าออกมาด้วยภาษาง่าย ๆ ตรง ไม่ปลอบจนหลงทาง และไม่ขู่

## สูตรดาราศาสตร์

อ้างอิง Jean Meeus, *Astronomical Algorithms* (ฉบับที่ 2)

| ค่า | ที่มา | ตรวจเทียบแล้ว |
|---|---|---|
| Julian Day | ch.7 | ตรง |
| ลองจิจูดดวงอาทิตย์ | ch.25 (ตำแหน่งปรากฏ) | คลาด 0.0017° จากตัวอย่าง 25.b |
| ลองจิจูดดวงจันทร์ | ch.47 ตาราง 47.A 59 เทอม + A1/A2/E | คลาด 0.00001° จากตัวอย่าง 47.a |
| Sidereal time | 12.4 | คลาด < 0.001° จากตัวอย่าง 12.a |
| ความเอียงแกนโลก | 22.2 | คลาด < 0.001° |
| ลัคนา | `atan2(cos RAMC, −(sin RAMC·cos ε + tan φ·sin ε))` | กวาดครบ 12 ราศีเรียงลำดับใน 24 ชม. |

ใช้ระบบ Tropical zodiac ตามมาตรฐานโหราศาสตร์ตะวันตก

**ข้อจำกัด:** ไม่รู้จัก DST อัตโนมัติ (มีเช็กบ็อกซ์ให้ติ๊กเองสำหรับประเทศที่มี) ·
ใช้ UT ≈ TT ไม่ชดเชย ΔT (ผลไม่ถึง 1 ลิปดาในศตวรรษที่ 20–21) · รองรับปี ค.ศ. 1600–2200

## โครงสร้าง

`index.html` ไฟล์เดียว แยกเป็นบล็อกสคริปต์ที่ทดสอบแยกกันได้

| บล็อก | เนื้อหา |
|---|---|
| `#engine` | คณิตศาสตร์ดาราศาสตร์ (pure function ไม่แตะ DOM) |
| `#signs` | 12 ราศี × 3 บทบาท |
| `#tarot-major` `#tarot-minor-1` `#tarot-minor-2` | ไพ่ 78 ใบ (ความหมายตั้ง/กลับหัว/ความรัก/งาน/คำแนะนำ) |
| `#feelings` | ชั้นอารมณ์ของไพ่ 78 ใบ + จังหวะเวลาตามชุดไพ่ |
| `#places` | 77 จังหวัดไทย + 73 เมืองทั่วโลก พร้อมพิกัดและเขตเวลา |
| `#analyze` | ตัววิเคราะห์คำถาม |
| `#reading` | เครื่องตีความ 3 สเปรด |
| `#cardart` | หน้าไพ่ SVG — ไพ่ชุดใหญ่วาดเฉพาะใบ 22 แบบ, ไพ่ชุดเล็กนับสัญลักษณ์ได้ตามเลข |
| `#ui` | หน้าจอและการโต้ตอบ |

ฟอนต์ Prompt จาก Google Fonts (ถ้าออฟไลน์จะ fallback เป็นฟอนต์ระบบ) นอกนั้นไม่มี asset ภายนอกเลย
รองรับมือถือ · `prefers-reduced-motion` · และการสั่งพิมพ์

## การทดสอบ

- เทียบค่าดาราศาสตร์กับตัวอย่างในตำรา Meeus (ตารางด้านบน)
- ลัคนากวาดครบ 12 ราศีเรียงลำดับใน 24 ชม. ที่กรุงเทพฯ / ลอนดอน / ซิดนีย์
- สุ่มอ่าน 900 รอบ: ไพ่ 9 ใบไม่ซ้ำกันเลย ไม่มีข้อความหลุด และไม่มีประโยคซ้ำภายในสเปรดเดียวกัน
- ตรวจตัววิเคราะห์คำถามด้วยคำถามตัวอย่าง 10 แบบ ว่าจับสัญญาณได้ตรง
- เดินครบ flow บน Chromium ทั้ง desktop และ mobile โดยไม่มี console error
